Import mail for {{ subject.name }}

Upload an export of {{ subject.name }}'s mailbox as an .mbox file. Unlist reads who sent each message and, for order and booking markup, its HTML. It keeps, per Organization, the dates, the number of messages, the kind of evidence and the subject line of the strongest one. It never stores a message body, and it deletes the uploaded file when the scan is done.

Gmail (Google Takeout)

  1. Open takeout.google.com while signed in to the Gmail account.
  2. Click "Deselect all", then select only "Mail". You can limit it to some labels; "All Mail data included" gives the most results.
  3. Create the export. Google emails a download link when it is ready, which can take hours or days.
  4. Download and unpack the archive. The mail is in Takeout/Mail/ as a file ending in .mbox. Upload that file here.

Spam and Trash in the export are skipped.

Other providers

Most mail programs can save a folder as mbox. In Thunderbird, add the account, then use the ImportExportTools NG add-on: right-click the folder, "Export folder" (or "Save all messages") as mbox. Providers with their own export (for example Fastmail, Posteo, mailbox.org) usually offer mbox or a format Thunderbird can open.

Outlook.com and Microsoft 365

These mailboxes are import-only in Unlist: Microsoft has turned off password sign-in for IMAP, so Unlist cannot connect to them live. Add the account to Thunderbird (it signs in through Microsoft's own page) and export the folders as mbox as above. Requests for these Subjects are handed over for them to send.

Live connection (optional)

Where the provider offers app passwords (Gmail with 2-Step Verification, Fastmail, iCloud, GMX, WEB.DE, Posteo, mailbox.org and many others), you can instead connect the mailbox: Unlist then scans it over IMAP, read-only, and sends approved requests from it.
