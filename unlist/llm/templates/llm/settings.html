Optional LLM

Unlist is complete without an LLM. It is off unless you switch it on here. When it is on, a language model helps with four jobs; everything it says is a suggestion, marked with where it came from. It changes nothing and sends nothing until you press the button that applies it, and every email still waits for your approval.

Recommended: a local, free model that runs on this machine or your own network, such as Ollama or the server of llama.cpp. Then nothing leaves your network. For example, with Ollama:

ollama pull llama3.1
Endpoint address: http://localhost:11434/v1
Model name:       llama3.1

When Unlist runs in a container, the host machine is usually http://host.docker.internal:11434/v1, or the name of an Ollama container on the same network, such as http://ollama:11434/v1.

Any OpenAI-compatible endpoint works, including a cloud provider's. A remote endpoint is someone else's service: it receives the data listed below, and its software is nonfree. Unlist will not use one until you have accepted that once.
