# Unlist guide

Plain-language help for the person who runs Unlist (the Operator). Read in this order the first time:

1. **[Install and run](install.md)**: requirements, the `./data` and `./key` folders, reaching Unlist on your network or behind HTTPS, upgrading, changing the password, every setting.
2. **[First run](first-run.md)**: create the Operator, add a Subject, record consent, import mail (Google Takeout and others), the discovery list, Cases, approving drafts, replies, deadlines, re-checks, Complaints, statistics, the breach check.
3. **[What Unlist does and does not do](legal.md)**: the legal basis, what is and is not promised, consent, and what data Unlist keeps.
4. **[Backup and restore](backup.md)**: make a backup, store it safely, restore it, test it.

Optional extras, each off until you turn it on:

- **[Live mailbox connection](live-connection.md)**: read-only IMAP and sending through the Subject's own address.
- **[Optional language model](llm.md)**: a local, free model for four small suggestions.
- **[Organization Lists](organization-lists.md)**: where contact data comes from, how to update it, correct it and share corrections.
